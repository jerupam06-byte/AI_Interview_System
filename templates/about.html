System Architecture & Design Decisions

Everything the developer must be able to explain in technical placement interviews.

1. Project Overview & Motivation

The AI-Powered Interview Preparation & Evaluation System is an end-to-end full-stack web application developed by Jerusha Pamella Felix M. for MCA campus placements. Unlike simplistic CRUD applications, this project demonstrates algorithmic NLP, transparent weighted evaluation, asynchronous speech interaction, and persistent analytics.

2. Core Evaluation Algorithm

Instead of relying on an opaque external black box for numeric grades, the core evaluation engine implements deterministic Natural Language Processing (NLP):

  • TF-IDF Vectorization: Uses scikit-learn's TfidfVectorizer to convert candidate and expected answers into numerical sparse vectors with unigrams and bigrams, discounting ubiquitous English stop-words.
  • Cosine Similarity (60% weight): Measures the cosine of the angle between the normalized vectors in high-dimensional feature space, representing semantic alignment.
  • Boundary-Aware Keyword Matching (20% weight): Performs regex-based whole-word and multi-word phrase matching (e.g. "global interpreter lock", "window functions") to guarantee technical rigor.
  • Answer Completeness & Coherence (10% weight): Inspects structural sentence boundaries and logical connectors ("because", "for example", "therefore").
  • Length Sanity Check (10% weight): Guards against overly terse or one-word answers, ensuring substantive depth. Empty answers receive strictly 0.

3. Differentiating Feature: Interview Gap Detector

Most mock interview tools provide a numeric score and stop there. Our system features the Interview Gap Detector:

  • Extracts demonstrated concepts vs. missing keywords across every answered question.
  • Maps weaknesses into skill categories (Python, SQL & Databases, Machine Learning, NLP, Data Analysis, HR Communication).
  • Renders a visual Skill-Gap Map highlighting Mastered Concepts, Developing Areas, and High-Priority Critical Gaps.
  • Generates a targeted revision checklist so candidates can convert test results directly into actionable study plans.

4. Technology Stack & Rationale

Backend: Flask (Python)

Lightweight, modular WSGI framework allowing clean separation of routes, services, and models without bloat.

NLP: scikit-learn

Fast, deterministic, self-contained vectorization and cosine similarity calculations.

Database: PostgreSQL & SQLite

Full SQLAlchemy ORM abstraction. Seamless local SQLite testing and hosted PostgreSQL (Neon) in production.

Deployment: Vercel

Serverless WSGI deployment with zero configuration and ephemeral stateless handling.

5. Security & Graceful Fallback Strategy

All user passwords are encrypted using Werkzeug's secure PBKDF2/SHA256 salted hashing. Authentication sessions are protected with HTTPOnly cookies. If OpenAI API keys are not supplied or experience network rate limits, the system seamlessly triggers its internal deterministic feedback engine, guaranteeing that the application never crashes during live demonstrations.
